# HanaCafe

カフェ「HanaCafe」を想定して制作した、ポートフォリオ用のWebサイトです。

WordPressを初めて使用し、オリジナルテーマを作成してサイトを構築しました。
既存テーマのテンプレートに依存せず、PHP・CSS・JavaScriptを用いて、デザインからコーディング、WordPressへの組み込み、サーバーへのデプロイまで一通り制作しています。

## 🌿 作品概要

### 制作目的

ポートフォリオ用のWebサイト制作を通して、以下の技術を実践的に学習・習得することを目的として制作しました。

* WordPressを使用したWebサイト制作
* PHPによるWordPressテーマの構築
* HTML / CSS / JavaScriptによるフロントエンド実装
* レスポンシブ対応
* Webサイトのデザイン・UI設計
* ローカル環境から本番サーバーへのデプロイ

### サイトコンセプト

コーヒーや紅茶、ベーカリー、ケーキ、ショコラなどを提供するカフェを想定し、写真を大きく使用した落ち着いた雰囲気のサイトを制作しました。

## ✨ 実装した機能・工夫点

### オリジナルWordPressテーマ

WordPressの既存テーマをベースにせず、オリジナルテーマ「HanaCafe」を作成しました。

主に以下のファイルを自作しています。

* `style.css`
* `index.php`
* `header.php`
* `functions.php`
* `page.php`
* 各種ページテンプレート
* `template-parts`
* CSSファイル
* JavaScriptファイル

### オープニング動画

サイトの冒頭に動画を配置し、ページ読み込み時に再生されるオープニング演出を実装しました。

JavaScriptを使用して動画の再生状態を取得し、オープニングからメインコンテンツへ自然に切り替わるようにしています。

### ヒーロースライダー

トップページには複数の画像を使用したスライダーを実装しました。

JavaScriptでスライドを切り替え、最後のスライドから最初のスライドへ自然につながるようにしています。

### スクロールアニメーション

`IntersectionObserver`を使用し、各セクションが画面内に入ったタイミングでコンテンツがフェードインするアニメーションを実装しました。

### メニューカテゴリー別ページ

Menuページから、

* Coffee
* Tea
* Bakery
* Chocolate

の各ページへ移動できる構成にしています。

カテゴリーごとに異なる背景画像を使用し、それぞれのメニューを見やすく表示しています。

### Newsページ

WordPressの投稿機能を利用してニュースを表示するページを作成しました。

記事一覧だけでなく、ページネーションにも対応しています。

### Galleryページ

複数の写真をグリッド形式で表示し、カフェの雰囲気を視覚的に伝えられるようにしました。

### レスポンシブ対応

PCだけでなくスマートフォンからも閲覧できるよう、画面幅に応じてレイアウトが変化するレスポンシブデザインを実装しています。

### ファビコン・ロゴ

オリジナルのロゴを制作し、サイト内のロゴおよびファビコンとして使用しています。

## 🚀 デプロイ

## 📌 制作を通して学んだこと

今回が初めてのWordPressを使用したWebサイト制作でした。

これまでのWebアプリケーション開発とは異なり、WordPressではテーマファイルと管理画面上のコンテンツを組み合わせてサイトを構築する必要があるため、WordPress特有の仕組みを理解しながら制作を進めました。

また、ローカル環境での制作だけで終わらせず、GitHubでソースコードを管理し、XServerへ実際にデプロイするところまで経験しました。

デザイン・コーディング・WordPressへの組み込み・公開まで、一連のWebサイト制作工程を実践できたことが今回の制作における大きな学びとなりました。
